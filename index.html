Tarik file HAR ke sini

.har atau .json · File baru ditambahkan ke data yang sudah ada

◈File HAR diproses 100% di browser dan tidak diunggah ke server mana pun. Chart.js dan Excel dimuat dari CDN. Thumbnail Instagram hanya dimuat jika Anda mengaktifkannya.

Cara ambil file HAR
  1. Buka instagram.com di Chrome laptop, login, lalu buka profil yang mau dianalisis.
  2. Buka DevTools → Network (Mac: ⌘⌥I; Windows: F12), centang Preserve log, pastikan rekaman aktif, dan kosongkan filter.
  3. Refresh halaman, lalu scroll pelan sampai semua post yang diinginkan ter-load.
  4. Klik ikon download di toolbar Network → pilih Export HAR (sanitized).
  5. Upload file tersebut ke sini.

Jangan pernah membagikan HAR non-sanitized. File tersebut bisa berisi cookie, token, dan data login.
